## 二、待补截图与拍摄步骤

以下截图建议在**交易日盘中**、**正常显示环境**下补拍，替换或补充现有图片。

1. **主工作台全景（v2.27.0）**
   - 加载「盘中盯盘」场景模板，窗口最大化；
   - 确保 Mega 菜单、时段页签、卡片网格均可见；
   - 截取包含涨停雷达、板块热力图、K 线、资金流向等核心卡片的全景。
2. **设置 · 外观页**
   - 按 `Ctrl/⌘ + ,` 打开设置（若使用中文输入法，请先切到英文，避免逗号键被输入法拦截）；
   - 依次展示：开机自启开关、配色主题网格、界面缩放四档、高对比开关。
3. **AI 问数助手**
   - 打开「AI 问数」卡片，输入一个盘面问题（如"今天涨停最多的板块"）；
   - 截取流式回答 + 工具调用引用的完整界面。
4. **分时复盘工作台**
   - 打开「K 线图」卡片，确认周期为「日」、已加载 K 线；
   - **双击任意一根蜡烛**，弹出复盘工作台；
   - 分别截取：回放控制条（播放 / 倍速 / 进度）、多日分时叠加（2/3/5 日）、分时量比副图。
5. **快脑决策 + 信号桥**
   - 打开「快脑决策」与「信号确认桥」卡片；
   - 截取决策日志、概率条、待确认信号单的界面。
6. **首次引导**
   - 方式一：设置 → 关于 →「重新查看新手引导」；
   - 方式二（全新状态）：删除数据库 `meta` 表中 `key='onboarding_done'` 的记录后重启。
7. **预警触发**
   - 新建一条贴近现价的预警，等待触发，截取系统通知、提示音状态与「触发历史」。
8. **亮色 / 高对比**
   - 主题切到「同花顺经典白」，再开启「高对比模式」，各截一张。

**拍摄建议**：统一使用 1080p 及以上分辨率；窗口最大化；隐藏无关程序与任务栏图标；保存为 PNG（无损）。

## 四、录制与导出指引

- **Windows**
  - 录屏 / 导出 MP4：[OBS Studio](https://obsproject.com/)（免费）；
  - 录制 GIF：[ScreenToGif](https://www.screentogif.com/)（可逐帧编辑、压缩体积）；
  - 截图：系统自带 `Win + Shift + S` 或 [ShareX](https://getsharex.com/)。
- **macOS**
  - 录屏：QuickTime Player（新建屏幕录制）或 OBS；
  - GIF / 短视频：[Kap](https://getkap.co/)；
  - 截图：`⌘ + Shift + 4 / 5`。
- **参数建议**
  - 视频：1920×1080、30 fps、H.264（MP4），单条控制在 1–3 分钟；
  - GIF：宽度 ≤ 960 px、帧率 12–15 fps、时长 ≤ 15 秒，避免体积过大；
  - README 中优先嵌入 GIF 或外链视频（如 B 站 / YouTube），不要把大体积 MP4 直接提交进 Git 仓库。
- **存放位置**
  - 原始工程与成片可放在 `docs/media/`（建议在 `.gitignore` 中忽略大体积源文件）；
  - 发布到视频平台后，在 README 与本页放入观看链接。
